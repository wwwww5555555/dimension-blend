# P2 渲染顺序审计与修正（v0.14.0）

## 一、审计结论（修正前）

用 grep 打出 `FRAG_P2` 的实际执行顺序：

| 位置 | 修正前 | 应为 | 判定 |
| --- | --- | --- | --- |
| ① | sRGB→线性 | 原始 RGB | ✅ |
| ② | S 曲线（0→1 端点）+ Unsharp | 明暗/对比 | ⚠️ 端点太软 |
| ③ | **颜色矩阵（AI 调色）** | 伪立体光照 | ❌ **错位** |
| ④ | 四色环境光 SoftLight | 四色环境光 | ❌ 顺序颠倒 |
| ⑤ | 伪立体光照 | 边缘光 | ❌ 顺序颠倒 |
| ⑥ | 边缘光 | **颜色矩阵（最后）** | ❌ **错位** |

**"死平"的直接成因**：矩阵在**光照之前**执行，它的降饱和/偏移先把人物压成一层灰，
后面的方向光和四色就成了在"平涂"上做微调 —— 层次已经被抹掉了，再怎么加都是灰的。
另外矩阵强度是 0.6，权重偏高。

## 二、修正后的顺序

```
① 原始 RGB（仅 sRGB→线性）
② S 曲线 smoothstep(0.2, 0.8, luma) + Unsharp     ← 先拉开明暗
③ 伪立体光照：迎光 Screen / 背光 Multiply（带环境暗色色相）
④ 四色环境光：SoftLight（方向加权 + 径向衰减）
⑤ 边缘光：轮廓带 × 内部熔断
⑥ 颜色矩阵：最后一步，强度 0.5，**保亮度**
```

## 三、三个排查项的具体结论

### 排查 1：ColorMatrix 是不是最后一步？是否把方差拉平？

**不是最后一步**（在 ③），已移到 ⑥。此外矩阵本身仍可能拉平方差，所以加了**保亮度**：

```glsl
vec3 cm = clamp(uColorMatrix * c, 0.0, 4.0);
float l0 = dot(c, LUMA);          // 矩阵前亮度
float l1 = dot(cm, LUMA);         // 矩阵后亮度
cm *= clamp(l0 / max(l1, 1e-4), 0.20, 3.0);   // 只取色相/通道比，亮度强制还原
c = mix(c, cm, uMatrixStrength * smoothstep(0.1, 0.6, a));
```
即使 AI 给的是一个"降饱和 + 抬暗部"的矩阵，输出亮度仍等于矩阵前 —— 明暗层次不可能被矩阵吃掉。
强度 0.6 → **0.5**。

### 排查 2：四色渐变是不是被写成了普通 mix？

**不是**。代码里有两处 `mix`，含义完全不同：

```glsl
vec3 quad = mix(quadH, quadV, 0.5);                    // ① 插值"渐变色场"本身（正确）
c = mix(c, softLight(c, quad), k * ...);               // ② 用 softLight 结果按 k 掺入
```
① 是在四个环境色之间做双线性插值，本来就是 `mix`；
② 的混合模式是 **`softLight(c, quad)`**（Pegtop：`(1-2s)b² + 2sb`），外层 `mix` 只控制**掺入比例 k**。
如果用 `c = mix(c, quad, k)`，那就是把环境色直接盖上去 —— 那才会洗白。

### 排查 3：Gamma 是否处理错，导致暗部被提亮？

**没有错**，链路是完整的：

| 环节 | 处理 |
| --- | --- |
| Bitmap 上传 | `setPremultiplied(false)` + `texImage2D`，**不做任何转换**（像素仍是 sRGB） |
| P1 / P2 采样后 | `pow(rgb, 2.2)` → 线性 |
| 中间所有 pass | 全在线性空间计算（阴影 Multiply、Screen、SoftLight 都要求线性） |
| 最终 FXAA | `pow(rgb, 1/2.2)` → 回 sRGB，且是**最后一个** pass |

两个已知的**精度**问题（不是 gamma 错误，但会被看成"发灰"）：
1. FBO 是 `RGBA8`，线性空间存 8bit → 暗部量化损失（暗部 banding）；
2. 背景模糊是在 sRGB 像素上做的（先模糊再 `pow`），数学上应在伽马空间前做。
两者都在观感阈值内，暂不改（改 FLOAT16 FBO 会显著增加显存）。

## 四、参数变化

| 参数 | 旧 | 新 |
| --- | --- | --- |
| `toneContrast` | 0.35 | **0.55** |
| S 曲线端点 | `smoothstep(0, 1)` | `smoothstep(0.2, 0.8)` |
| 矩阵强度 | 0.6 | **0.5** |
| 矩阵保亮度 | 无 | `l0/l1` 强制还原 |
