# 逆光"灯泡"修复（v0.15.0）

## 现象与根因

逆光场景下人物整体发亮，像自带光源。**两个独立原因叠加**：

| 原因 | 证据 |
| --- | --- |
| ① 逆光时没有任何压暗 | P2 里只有 `uBacklit` 参与 P2-c 阴影，**人物本体完全没读它** → 逆光与非逆光的人物亮度一样，而背景因镜头光晕更亮，人物反而更"白" |
| ② 边缘光 mask 太宽，漏进内部 | rim 用 `a*(1-a)*4`：a=0.85 时仍有 **0.51**；P2-w 用 `1-smoothstep(0.90,0.95,a)`：a=0.88 时约 **0.9**。等于脸和衣服都落在"边缘"里 |

## 修正 1：逆光剪影压暗（在边缘光之前）

```glsl
// ===== ②b 逆光剪影压暗（必须在边缘光之前）=====
c *= mix(1.0, uBacklitDarken, uBacklit);   // 0.58 → 压暗 42%
```
位置很关键：放在 ② 明暗强化之后、③ 伪立体光照之前。
压暗之后再走 ③ 方向光 / ④ 四色 / ⑤ 边缘光，阴影层次才有地方"长"；
如果放在最后，会把前面拉出的层次一起抹掉。

## 修正 2：严格环带（rim 与 wrap 用同一套阈值）

```glsl
// 0.30→0.70 升起，0.80→0.95 归零；a>0.95（实心内部）恒为 0
float band = smoothstep(0.30, 0.70, a) * (1.0 - smoothstep(0.80, 0.95, a));
c += uRimColor * pow(facing, 1.5) * band * uRimStrength * uLightIntensity * 2.0;
```

| a | 旧 `a*(1-a)*4` | 新环带 |
| --- | --- | --- |
| 0.5 | 1.00 | 0.55 |
| 0.70 | 0.84 | 1.00 |
| 0.85 | **0.51** | **0.38，且迅速归零** |
| 0.95 | 0.19 | **0** |

⚠️ 规格给的 `smoothstep(0.95, 0.8, maskInner)` 是 `edge0 > edge1`，**GLSL 规范里是未定义行为**
（驱动可能返回 0、可能反向）。等价且合法的写法是 `1.0 - smoothstep(0.80, 0.95, a)`。

光向限制保留并加严：`facing = max(0, dot(nOut, normalize(lightDir)))`，
背光侧轮廓 `facing=0` → 完全不发光。

P2-w 光包裹同样换环带：
```glsl
wrapMask *= smoothstep(0.30, 0.70, wrapMask) * (1.0 - smoothstep(0.80, 0.95, a));
```

## 修正 3：逆光下四色权重减半 + 向暗部靠拢

```glsl
float quadK  = uQuadStrength * mix(1.0, 0.5, uBacklit);        // 权重减半
vec3 quadAdj = mix(quad, shadowChroma * 0.22, uBacklit * 0.55); // 色彩向背景暗部偏
```
物理依据：逆光时天空极亮，但那是**背后**的光，照不到人物正面；
环境光如果按正常权重叠上去，等于给人物正面补了一盏不存在的大灯。

## 修正 4：内部亮度上限（0.8）

```glsl
// 只压内部：轮廓带保留镜面溢出，否则边缘光会被一起削平
c = mix(c, min(c, vec3(uLumaCap)), 1.0 - band);
```
放在 ⑥ 颜色矩阵之后（最后一层）。`0.8` 是**线性**值（≈ sRGB 0.91），所以不会把正常画面压灰，
只拦"矩阵增益 + 叠加把亮度推爆"的情况。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `backlitDarken` | 0.58 | 压暗 42%（规格 30~50%）；1 = 关闭 |
| `personLumaCap` | 0.8 | 内部亮度上限 |
| 环带阈值 | 0.30/0.70/0.80/0.95 | 写死在 shader，rim 与 wrap 共用 |

## 副作用（如实）

- 逆光压暗是**全人物**乘的，所以边缘光本身也被压了一次；`uRimStrength` 若原本调得刚好，
  逆光下会显得弱一点（这符合物理：逆光轮廓光应该比顺光更突出，可把 `rimStrength` 单独调高）。
- 亮度上限 0.8 对常规曝光无影响，但**白衣服 + 强补光**的场景会看到轻微截断。
